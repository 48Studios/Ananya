Two independent skills live under `.agents/skills/`, each a self-contained documentation package consumed by the agent runtime:
- `shadcn/` — a UI component skill. `SKILL.md` is the entry point declaring `user-invocable: false` and allowed shell tools (`npx shadcn@latest`, `pnpm dlx shadcn@latest`, `bunx --bun shadcn@latest`). It references sibling rule files under `rules/` (styling, forms, composition, icons, chat, base-vs-radix) as enforced critical rules, plus reference docs (`cli.md`, `registry.md`, `customization.md`). An `agents/openai.yml` provides display metadata for OpenAI-compatible agents; `evals/evals.json` holds evaluation fixtures.
- `turborepo/` — a monorepo build-system skill. `SKILL.md` declares `metadata.version: 2.10.5` and is organized into decision trees, anti-patterns, common configurations, and a reference index pointing to topic folders under `references/` (configuration, caching, environment, filtering, ci, cli, best-practices, watch, boundaries). A `command/turborepo.md` file exists alongside.

Dependency direction is one-way: both skills are pure Markdown knowledge bases read by the agent; they do not import code from the rest of the repo. The shadcn skill additionally invokes the external `shadcn` CLI at runtime via Bash tool calls declared in its frontmatter.
