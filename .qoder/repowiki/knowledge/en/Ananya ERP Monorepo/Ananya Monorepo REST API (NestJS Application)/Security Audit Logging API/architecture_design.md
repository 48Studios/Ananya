Standard NestJS feature module with three files: `security-audit.module.ts` registers the controller and service and exports the service for reuse; `security-audit.controller.ts` exposes `GET /security/audit` accepting optional `category` and `userId` query params that delegate to the service; `security-audit.service.ts` provides two operations — `record()` inserts an audit row via Drizzle ORM (`@ananya/database`) into the `securityAuditLogs` table, and `getLogs()` builds a filtered, paginated (limit 100) descending-by-createdAt query. The module depends only on the shared database package (`@ananya/database`) for schema and query helpers (`desc`, `eq`); there is no internal sub-layering beyond the controller/service split.
