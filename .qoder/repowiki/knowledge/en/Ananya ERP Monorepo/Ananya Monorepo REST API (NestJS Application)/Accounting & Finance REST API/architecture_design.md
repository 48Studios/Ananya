Each subdirectory under apps/api/src is a self-contained NestJS feature module following the standard controller/service/module triad plus a local dtos.ts. Controllers are thin HTTP adapters that delegate all logic to services; services own business rules (e.g. generating next numbers, invoking domain-entity methods like `post()`, `reverse()`, `void()`) and persist via repository interfaces injected through token constants (`ACCOUNT_REPOSITORY`, `JOURNAL_ENTRY_REPOSITORY`, `PAYMENT_REPOSITORY`). Repository implementations live outside this scope in `../infrastructure/repositories/drizzle-*.repository` and are wired in each module's provider array. Cross-entity coordination happens at the service layer — PaymentsService depends on ReceivableInvoicesService and PayableInvoicesService to auto-allocate posted payments. Domain types (entities, enums, repository interfaces) come from the external `@ananya/finance` package; DTOs are defined locally per module. Modules export their services so other features can compose them.
