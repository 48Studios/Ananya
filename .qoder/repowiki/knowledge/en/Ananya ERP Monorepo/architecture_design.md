The root orchestrates four runtime services (web_app, api, ml_service, e2e_tests) plus shared_packages via a pnpm workspace (`packages/*`, `apps/*`) and Turborepo task graph. `turbo.json` declares global env vars (DATABASE_URL, JWT_SECRET, NEXT_PUBLIC_*), enforces build/lint/type-check ordering with `^build` dependencies, and caches outputs under `dist/**` and `.next/**`. `compose.yml` defines the production container topology: Postgres as the shared data store, an optional migrate/worker profile, the NestJS API depending on DB health, the Next.js web proxying to the public API URL, and the FastAPI ML service behind a healthcheck; overrides in `compose.local.yml` / `compose.prod.yml` switch between local builds and published GHCR images. Cross-service contracts are enforced by shared packages under `packages/` (database schema, domain models, UI primitives) consumed by both the API and web apps, while `ai_test_tools` seeds deterministic test data against the running API and `agent_skills` provides AI-assisted dev guidance for the same codebase.
