The module exposes a two-layer design: `base.py` declares the `BaseTrainer` ABC with `train`, `save`, and `load` abstract methods plus a `model_type` class attribute, establishing the contract all trainers must implement. `classifier.py` provides the concrete `CategoryClassifierTrainer` implementing this contract for ERP product category classification by building three scikit-learn candidates (character n-grams, word n-grams, and a hybrid FeatureUnion), training each via `Pipeline.fit`, evaluating with accuracy and top-3 accuracy, and selecting the best by validation accuracy. The `__init__.py` re-exports only `BaseTrainer` and `CategoryClassifierTrainer`. Cross-cutting concerns are delegated outward: configuration comes from `..config.settings`, optional progress reporting uses a `progress` callback passed into `train`, and TUI updates are emitted via `..tui.emit_event`/`TrainingUpdateEvent` inside try/except blocks so UI failures do not break training. Artifacts are serialized with `pickle` and accompanied by a JSON metadata file written alongside the model.
