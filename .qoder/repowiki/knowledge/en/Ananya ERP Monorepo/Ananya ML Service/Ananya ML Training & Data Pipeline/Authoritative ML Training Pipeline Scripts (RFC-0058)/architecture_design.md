Flat package of independent CLI entry points under `apps/ml/pipeline/`, orchestrated by `run_training.py` which calls each stage sequentially in a fixed order: collect → validate → build_dataset → train → evaluate → deploy. Each script is self-contained with its own `argparse` CLI and `if __name__ == "__main__"` block, so stages can be run standalone or as part of the orchestrator. Data flows through JSON artifacts on disk (`apps/ml/data/raw_collected_records.json` → `validated_records.json` + `quarantine.json` → versioned snapshot under `apps/ml/data/datasets/<datasetVersion>/train.json,val.json,duplicate_pairs.json,metadata.json`) rather than in-memory objects, making the pipeline filesystem-driven. Model artifacts are pickled scikit-learn pipelines saved into `apps/ml/models/registry/v<version>/metadata.json` + `category_classifier.pkl`, with `deploy.py` copying the champion to `apps/ml/models/category_classifier.pkl` and writing `model_metadata.json` plus an active deployment log. Dependencies inside the module are one-directional: only `run_training.py` imports from sibling modules; all other scripts depend only on stdlib, numpy, and scikit-learn.
