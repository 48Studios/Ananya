Run the full pipeline via `python apps/ml/pipeline/run_training.py --version <ver> [--feedback-file ...] [--extra-catalog ...] [--no-deploy]`; individual stages are also runnable as CLIs (e.g. `collect.py`, `validate.py`, `build_dataset.py`, `train.py`, `evaluate.py`, `deploy.py`). Deployment requires either an existing `evaluation_report.json` with `promotionEligible` set or `--force`; rollback is supported via `deploy.py --rollback`. The orchestrator writes a summary report to `apps/ml/models/registry/v<version>/pipeline_summary.json`.
