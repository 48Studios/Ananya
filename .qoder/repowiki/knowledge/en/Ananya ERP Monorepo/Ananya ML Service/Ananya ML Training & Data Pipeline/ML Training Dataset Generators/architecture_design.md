Flat package of one generator class per ML task, all re-exported through `__init__.py` as the public API. Each module follows a uniform contract: a class exposing a single `generate(records: List[ProductRecord]) -> List[TaskExample]` method that consumes `..schemas.product.ProductRecord` and emits typed examples from `..schemas.tasks`. Data transformation logic is delegated to sibling packages under `..processors.*` (normalization, deduplication), keeping generators purely data-shaping. The `classification` module additionally exposes a standalone `generate_text_variations` helper for synthetic text augmentation. Dependency direction is strictly inward toward schemas and processors — no cross-imports between generator modules.
