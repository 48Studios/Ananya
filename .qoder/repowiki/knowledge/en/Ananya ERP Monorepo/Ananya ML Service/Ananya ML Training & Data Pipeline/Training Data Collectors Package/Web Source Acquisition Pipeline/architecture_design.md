The module is organized as a layered pipeline with clear dependency direction: `registry.py` defines declarative source configuration (`SourceConfig`, `SourceRegistry`, `RateLimitConfig`) loaded from YAML; `policy.py` provides crawl compliance via `CrawlPolicyManager` (robots.txt parsing, per-domain rate limiting, Retry-After handling); `discovery.py` runs `DiscoveryEngine` to build page/document queues from sitemaps, HTML link extraction, robots-declared sitemaps, and category seeds while enforcing domain allowlists and URL canonicalization; `downloader.py` implements `ResilientDownloader` with streaming HTTP via httpx, exponential backoff, conditional GET (ETag/Last-Modified), SHA-256 provenance hashing, size limits, and atomic file writes into `web/catalogs/documents/datasets/metadata` subdirs; `extractor.py` hosts `ContentExtractor` which parses HTML (JSON-LD Schema.org Product, breadcrumb, spec tables) and PDFs (via pypdf + optional datasheet extractor service) into `ProductRecord`s; `acquisition.py` persists crawl state through `AcquisitionStore` (thread-safe JSON-backed record DB with DISCOVERED/DOWNLOADED/PROCESSED/SKIPPED/FAILED lifecycle) and a sidecar `DocumentTextCache` keyed by content hash. The package `__init__.py` re-exports all public types so callers consume a flat API surface.
