Raw files are written under a configurable `raw_storage_base` with fixed subdirectories (`web`, `catalogs`, `documents`, `datasets`, `metadata`); acquisition state lives in an `acquisition.json` file within a metadata directory, and parsed PDF text is cached as `{content_hash}.json` files in a separate cache directory. Worker counts are resolved via `resolve_document_worker_counts(document_workers, rate_limit)` to split download vs parse concurrency based on per-domain `max_concurrent` policy.
