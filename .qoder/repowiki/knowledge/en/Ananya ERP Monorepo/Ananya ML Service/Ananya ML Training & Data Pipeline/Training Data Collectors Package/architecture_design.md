The package exposes a uniform `BaseCollector` interface (with `collect()`, `last_stats`, `source_health`) implemented by five concrete collectors — `AnanyaDbCollector`, `ManufacturerCatalogCollector`, `DistributorFeedCollector`, `DocumentCollector`, and `AutonomousWebCollector` — all re-exported from `__init__.py`. The first four are single-source ingestors; `AutonomousWebCollector` is a multi-source orchestrator that composes an internal pipeline (`web/registry.py` → `discovery.py` → `downloader.py` → `extractor.py` → `acquisition.py`) over declarative sources in `config/sources.yaml`, then delegates to the shared downstream training pipeline (`..processors.{normalization,validation,deduplication,cross_source}`, `..generators.*`, `..datasets.splitter`) to produce versioned dataset splits. All collectors emit `ProductRecord` models from `..schemas.product` and share cross-cutting concerns: `LiveProgress` for TUI events via `..tui.emit_event`, `settings.base_dir` / `training_data_dir` for paths, and per-source health tracking keyed by source id.
