This module is a leaf placeholder structure under `apps/ml/training/datasets/` that reserves three sequential processing stages — `cleaned/`, `normalized/`, and `evaluation/` — each containing only a `.gitkeep` file. The directories are intended to be populated by upstream pipeline steps with versioned dataset artifacts (e.g., Parquet/CSV files) so downstream consumers can read data in a consistent, stage-scoped layout. No source code or configuration lives here; the structure itself defines the artifact contract between pipeline stages.
