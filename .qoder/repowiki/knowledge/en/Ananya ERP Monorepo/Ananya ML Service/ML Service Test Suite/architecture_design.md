Flat pytest package under `apps/ml/tests/` with one test file per production subsystem: API surface (`test_ml_service.py` uses `fastapi.testclient.TestClient` against `apps.ml.app.main.app`), classification & manufacturer resolution (`test_category_resolution.py`, `test_manufacturer_resolution.py` driven by JSON fixtures in `category_resolution_cases.json` / `manufacturer_resolution_cases.json`), autonomous web collection (`test_autonomous_collection.py` covering source registry, robots.txt, sitemap parsing, HTML/PDF extraction, acquisition store, CLI), training runner control plane (`test_training_runner.py` stubbing every pipeline step via `monkeypatch.setattr` on `apps.ml.pipeline.*`), and auxiliary services (datasheet extraction, progress, workspace, attribute intelligence, component attribute intelligence, data coverage, document acquisition concurrency). Tests import directly from `apps.ml.app.services`, `apps.ml.training.collectors`, and `apps.ml.app.schemas` — there is no shared test library; each file is self-contained.
