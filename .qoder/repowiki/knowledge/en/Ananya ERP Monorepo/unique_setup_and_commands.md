`pnpm build` runs Turborepo across all apps and packages; `pnpm dev` boots every child concurrently via Turbo; `pnpm db:{generate,push,migrate,setup,bootstrap}` target the `@ananya/database` package; `pnpm ml:setup` creates the Python venv and installs ML requirements; `pnpm qa` chains lint → check-types → test → build → e2e; Docker stacks are composed with `docker compose -f compose.yml -f compose.local.yml up --build` (local) or `compose.prod.yml` (published images).
