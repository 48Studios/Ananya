The module is a flat documentation tree organized by topic rather than technology. The root `README.md` acts as a navigation hub linking to five top-level areas: `architecture/` (high-level design, project structure, DDD, component consolidation), `rfcs/` (a sequentially numbered archive of 61 design proposals from `0001-inventory-ledger.md` through `0061-category-intelligence-v2.md`, each following the lifecycle states Draft/Accepted/Superseded/Rejected defined in `rfcs/README.md`), `standards/` (coding standards, new module/package guides, PR review checklist, workspace packages policy), `development/` (setup, local dev, testing), and operational docs at the root (`AUTHENTICATION.md`, `DATA_LIFECYCLE.md`, `ML_OPERATIONS.md`, `SCANNER_APP.md`, `INFORMATION_ARCHITECTURE.md`). Subdirectories `api/`, `database/`, and `benchmarks/` hold focused reference docs. There is no build step or generated output — the module is pure Markdown consumed by contributors and reviewers.
