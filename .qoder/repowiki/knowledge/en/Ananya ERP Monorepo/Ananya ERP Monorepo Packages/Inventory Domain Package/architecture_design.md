Organized as a domain package (`@ananya/inventory`) that re-exports ten sub-domains from `src/index.ts`: locations, components, manufacturers, categories, ledger (inventory transactions), adjustments, units, projection, reservations, batches, serials, and attributes. Each sub-domain follows a consistent internal layout: an aggregate entity file (e.g. `location.ts`, `component.ts`), a repository interface declaring CRUD/query methods typed against the aggregate (e.g. `LocationRepository`, `ComponentRepository`, `InventoryTransactionRepository`), one or more use-case classes implementing business workflows via constructor-injected repositories (e.g. `CreateLocation`, `CreateComponent`, `CalculateInventoryProjection`), and a dedicated `*.errors.ts` module exporting domain-specific error classes. The `ledger` sub-domain defines transaction types in `transaction-types.ts` and is consumed by `projection` to compute running inventory balances. The package depends only on `@ananya/core` and exposes its public surface through barrel `index.ts` files per sub-domain plus the root index; build output goes to `dist/` via CommonJS compilation from `tsconfig.build.json`, while type consumers resolve directly to `src/index.ts`.
