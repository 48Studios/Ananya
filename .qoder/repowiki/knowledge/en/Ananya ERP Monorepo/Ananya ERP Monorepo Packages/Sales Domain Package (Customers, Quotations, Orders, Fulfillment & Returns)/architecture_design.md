The package is organized as a flat domain layer under `src/`, split into five sub-domains (`customers`, `quotations`, `sales-orders`, `fulfillment`, `returns`), each following an identical three-file pattern: a `.ts` file defining the entity class and value types, a `*.repository.ts` file declaring a read/write repository interface plus a `FindMany*Options` query filter type, and an `index.ts` re-exporting them. The package root `src/index.ts` re-exports all five sub-domains, making this package a single facade consumed by other packages. Each repository interface exposes a uniform contract — `findById`, `findByXxxNumber`, `findMany(options)`, `save(entity)`, and `generateNextXxxNumber()` — so implementations can be swapped without changing callers. Entities are pure TypeScript classes with private constructors, static `create`/`rehydrate` factories, and business methods that mutate state and update timestamps; they depend only on shared primitives from `@ananya/core` (e.g. `ObjectId`). The package has no runtime HTTP or framework dependencies — it depends solely on `@ananya/core` and `@ananya/inventory`, keeping it a domain-only library.
