The package is a pure domain layer published as `@ananya/finance`. It is organized into six feature folders (`accounts`, `journals`, `receivables`, `payables`, `payments`, `banking`), each following a consistent three-file layout: an entity class file (e.g. `account.ts`, `journal-entry.ts`) defining the aggregate root plus value-object-like props interfaces, a sibling `*.repository.ts` declaring an interface contract for persistence, and an `index.ts` barrel re-exporting both. The package root `src/index.ts` re-exports every feature barrel so consumers import from `@ananya/finance` directly. Entities depend only on `@ananya/core` (for `ObjectId` generation) — there are no cross-feature imports inside this package, keeping each aggregate isolated. Repository interfaces define read/write contracts (`findById`, `findMany`, `save`, etc.) but contain no implementation, leaving storage to be provided by consuming layers. Build output targets CommonJS via `tsconfig.build.json` with `rootDir: src` and `outDir: dist`; tests use Vitest (`vitest.config.ts`).
