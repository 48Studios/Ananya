The package is an ESM-only (`"type": "module"`) npm package that exposes three preset entry points through `package.json` `exports`: `./base`, `./next-js`, and `./react-internal`. Each preset is a single file exporting an ESLint flat-config array. `base.js` composes the foundation: `@eslint/js` recommended rules, `eslint-config-prettier`, `typescript-eslint` recommended rules, `eslint-plugin-turbo` (with `turbo/no-undeclared-env-vars` set to warn), `eslint-plugin-only-warn`, and ignores for `dist/**`. `react-internal.js` extends `baseConfig` and adds React/React Hooks plugins with browser+service-worker globals and disables legacy JSX scope. `next.js` also extends `baseConfig` but re-exports as `nextJsConfig`, adding Next.js-specific ignores (`.next`, `out`, `build`, `next-env.d.ts`) via `eslint/config`'s `globalIgnores`, React globals, and both `recommended` and `core-web-vitals` rule sets from `@next/eslint-plugin-next`. Dependency direction is strictly one-way: the React and Next presets depend on `base.js`; nothing depends back on it. All runtime dependencies are declared under `devDependencies` since this package ships only configuration objects.
