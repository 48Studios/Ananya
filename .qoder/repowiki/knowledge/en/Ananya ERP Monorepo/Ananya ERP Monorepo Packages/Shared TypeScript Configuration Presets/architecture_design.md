The package is a pure configuration-only npm module (`@ananya/typescript-config`) with no runtime code — `package.json` marks it private and publishes only the JSON files. All presets extend a single `base.json` root that enforces shared compiler options (strict mode, ES2022 target/lib, Bundler module resolution, isolatedModules, declaration+declarationMap). Domain-specific presets then layer on top: `library.json` adds verbatimModuleSyntax for TS libraries, `react-library.json` enables react-jsx JSX transform, `nextjs.json` configures Next.js plugin, preserve JSX, allowJs, and noEmit, and `nest.json` switches to CommonJS + Node moduleResolution and enables decorators/source maps for server-side output. Each preset declares its own `$schema` pointing to the tsconfig schema so IDEs validate them independently.
