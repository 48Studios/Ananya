The package is a pure TypeScript domain layer (`@ananya/projects`) with no persistence implementation. It exposes three sub-domains via barrel `index.ts` files: `projects/`, `tasks/`, and `time/`. Each sub-domain follows an identical internal layout — a domain class (`Project`, `Task`, `TimeEntry`) plus its props/value-type definitions, a dedicated `*.repository.ts` declaring an interface (`ProjectRepository`, `TaskRepository`, `TimeEntryRepository`) with `findById`/`findByNumber`/`findMany`/`save`/`delete`/`generateNext*Number` methods, and a `project.errors.ts` file holding domain-specific error classes. The root `src/index.ts` re-exports all three sub-domains. Domain classes use private constructors with static `create`/`rehydrate` factory methods, enforce invariants inside those factories and behavior methods, and derive IDs from `ObjectId.generate()` provided by the shared `@ananya/core` dependency. Dependency direction is one-way: this package depends only on `@ananya/core` and is consumed by other packages; it defines contracts (repository interfaces) that downstream implementations must satisfy.
