Organized as a domain-layer package (`@ananya/manufacturing`) that depends only on `@ananya/core` (for `ObjectId`, `DomainError`) and `@ananya/inventory`. Each subdomain is a self-contained folder under `src/` (`boms`, `production-orders`, `material-consumptions`, `finished-goods`, `traceability`) exposing an `index.ts` barrel re-exporting its entity, errors, and repository interface. Entities are implemented as classes with private constructors and static `create` / `rehydrate` factory methods, encapsulating business rules and status transitions; repository interfaces (e.g. `BillOfMaterialsRepository`, `ProductionOrderRepository`) are declared in sibling `*.repository.ts` files so the package remains persistence-agnostic. The package root `src/index.ts` re-exports all five subdomains, making them the public API surface. There are no application services or infrastructure implementations — this package owns pure domain logic and contracts only.
