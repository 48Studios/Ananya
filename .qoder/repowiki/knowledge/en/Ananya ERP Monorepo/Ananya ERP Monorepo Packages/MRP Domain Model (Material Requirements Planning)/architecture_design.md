The package is a pure TypeScript domain layer organized as six sub-packages under `src/` — `runs`, `materials`, `purchases`, `production`, `capacity`, and `messages` — each exposing an aggregate class plus a matching `<aggregate>.repository.ts` interface and a barrel `index.ts`. A single `src/index.ts` re-exports all aggregates so consumers import from `@ananya/mrp` uniformly. Each aggregate enforces its own invariants via a private constructor paired with static `create` (for new objects) and `rehydrate` (for persistence round-trips), and exposes state only through getters; mutable behavior lives on methods like `start`, `complete`, `accept`, `reject`, and `markImplemented` that guard transitions by current status. Repository interfaces are defined per aggregate but not implemented here, keeping the package free of persistence concerns and depending only on `@ananya/core`. Tests in `mrp.spec.ts` exercise the core invariants (shortage calculation, capacity utilization, recommendation lifecycles).
