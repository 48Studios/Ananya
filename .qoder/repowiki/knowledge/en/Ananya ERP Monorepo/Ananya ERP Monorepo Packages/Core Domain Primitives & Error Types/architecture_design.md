The package is a small, flat TypeScript library with no runtime dependencies. `src/index.ts` re-exports two sub-modules: `object-id.ts`, which defines an immutable `ObjectId` value object wrapping a string UUID (with static `create`/`generate` constructors and `equals`/`toString`), and `errors/`, which defines a base `DomainError` extending native `Error` plus three concrete subclasses (`ValidationError`, `NotFoundError`, `BusinessRuleError`) that all delegate to the base constructor. The package is private (`private: true`) and published only as a workspace dependency; its `package.json` exposes both a compiled `dist/index.js` entry point and raw `.ts` types for IDE support, built via `tsc -p tsconfig.build.json` and tested with Vitest.
