The package is organized as a flat set of domain sub-packages under `src/`, each following the same four-file layout: `<entity>.ts` (domain class + props), `<entity>.repository.ts` (persistence interface), `<entity>.errors.ts` (domain-specific error classes), and an `index.ts` barrel re-exporting them. The top-level `src/index.ts` re-exports all five sub-packages (`warehouses`, `stock-counts`, `cycle-counts`, `transfers`, `policies`). Each sub-package defines a repository interface that abstracts persistence (find/save/findMany/generateNext*Number) so implementations live outside this package; the domain classes themselves are pure — they construct IDs via `ObjectId.generate()` from `@ananya/core` and throw typed errors from their sibling `.errors.ts` file. Dependencies flow inward only to `@ananya/core` and `@ananya/inventory`; nothing in this package depends on other warehouse sub-packages.
