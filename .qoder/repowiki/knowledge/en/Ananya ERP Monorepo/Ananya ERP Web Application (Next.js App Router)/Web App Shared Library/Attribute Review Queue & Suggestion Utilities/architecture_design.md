Three sibling pure-utility modules under `apps/web/lib` that transform backend DTOs into UI-facing labels, decisions, and affordances without any DOM or framework coupling.

- `attribute-review-queue.ts` is the largest: it owns the queue's tab taxonomy (`ATTRIBUTE_QUEUE_TABS`, `ATTRIBUTE_ISSUE_TYPES_BY_TAB`), maps persisted `issueType` values to tabs via `findingMatchesTab`/`tabIssueTypeFilter`, derives tab counts from backend-provided grouped counts, and exposes decision/state/permission helpers (`canDecideAttributeFinding`, `deriveAttributeReviewPermissions`, `canApplyAttributeFinding`, `canAcceptAndApplyAttributeFinding`). It centralizes all copy (status labels, issue type labels, decision copy, apply tooltips) so wording stays consistent with the backend's advisory stance. Apply flow logic (`attributeApplyAction`, `attributeDefinitionProposal`, `attributeApplyConfirmation`) mirrors the API's `resolveAttributeApplyAction` and enforces that only families listed in `ATTRIBUTE_APPLY_RULES` may mutate the library.
- `attribute-suggestions.ts` handles AI suggestion presentation: classifies each suggestion into one of five states (`SUGGESTED`, `CONFLICT`, `MATCHES_EXISTING`, `UNVERIFIED_EXISTING`, `RELEVANT_ONLY`) via `attributeSuggestionState`, groups them (`groupAttributeSuggestions`), and reconciles them against the form's current value (`reconcileAttributeSuggestion`) so the form is authoritative over the server's recorded value. Bulk vs per-row apply rules are separated (`canAcceptSuggestion` vs `canApplyIndividually` vs `canApplySuggestionInBulk`), and `attributeValuePatch` produces the exact patch shape the editor expects.
- `attribute-units.ts` derives the set of selectable units for a QUANTITY attribute from the authoritative unit catalog (`UnitDto[]`), always ensuring the definition's default unit and the current unit are present even if not yet cataloged.

Dependency direction is strictly inward: these files import shared vocabulary from `intelligence-review-filters`, `component-review-queue`, `attribute-value-equivalence`, and API DTO types from `./api/*`, but nothing in this module imports UI components or application state. They are consumed by queue/suggestion screens as pure functions.
