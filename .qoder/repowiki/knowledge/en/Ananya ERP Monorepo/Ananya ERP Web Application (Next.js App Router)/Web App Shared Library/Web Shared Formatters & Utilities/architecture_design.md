Three small, independent utility files under `apps/web/lib/` with no internal dependencies between them:
- `formatters.ts` exports pure functions (`formatNumber`, `formatCurrency`, `formatPercentage`, `formatQuantity`, `formatDate`) that accept `null | undefined` values plus an optional fallback and never throw — they coerce strings to numbers, guard against NaN/infinity, and use `toLocaleString` / `toFixed` / `toLocaleDateString`.
- `utils.ts` is a thin re-export barrel: it wraps `clsx` + `twMerge` into a `cn(...)` helper and re-exports everything from `formatters.ts` so consumers import from `lib/utils` as a single entry point.
- `select-utils.ts` provides `extractSelectItems(children)`, which recursively walks a React node tree via `React.Children.forEach`, pulls out elements whose props include a `value`, deduplicates by value using a `Set`, and emits `{ value, label }` pairs (label resolves from `props.label` → `props.children` → `props.value`). It also adds loose numeric/string equivalents of each value for matching.
Dependency direction is one-way: `utils.ts` depends on `formatters.ts`; `select-utils.ts` is standalone. No runtime framework coupling beyond React in `select-utils.ts`.
