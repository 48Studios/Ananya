Three sibling Next.js App Router route segments (`journal-entries`, `payments`, `chart-of-accounts`), each exporting a default `'use client'` React component. The `journal-entries/page.tsx` and `payments/page.tsx` follow an identical layout: a `PageHeader` with actions, a grid of `StatCard` summaries, and an `EntityDataTable` driven by a `ColumnDef<...>[]` array from `@tanstack/react-table`. Data sources differ per page — `journal-entries` uses in-memory mock data via `useState`, while `payments` fetches live data through `financeApi.getPayments()` inside a `useEffect` with loading/error state rendered via `LoadingState`/`ErrorState` components. `chart-of-accounts/page.tsx` is a thin re-export shim that delegates rendering to the existing `../accounts/page` component, keeping the `/chart-of-accounts` URL alias without duplicating logic. All pages compose shared primitives from `@/components/ui/*` (button, page-header, stat-card, entity-data-table, status-badge, error-state, loading-state) and formatting helpers from `@/lib/utils` (`formatCurrency`, `formatDate`).
