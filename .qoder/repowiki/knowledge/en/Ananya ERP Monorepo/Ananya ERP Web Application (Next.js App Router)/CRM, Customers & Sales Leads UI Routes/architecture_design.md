Three Next.js App Router route groups under `apps/web/app/`: `crm/page.tsx` renders a pipeline-stage overview; `customers/` and `leads/` each expose a list page plus an `[id]/page.tsx` detail page. Every page is a React client component (`"use client"`) that owns its state via `React.useState` over inlined mock arrays (no server-side data fetching). List pages compose a consistent layout: `PageHeader` + three `StatCard`s + an `EntityDataTable` from `@/components/ui`, with column definitions typed via `@tanstack/react-table`'s `ColumnDef`. Detail pages read the route id through `next/navigation`'s `useParams` and render static profile cards. There is no internal service layer — all business logic (filter configs, computed stats like total pipeline value) lives inline in the page components, and navigation between list and detail uses Next `<Link>` to `/customers/[id]` and `/leads/[id]`.
