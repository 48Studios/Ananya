The module is a collection of React Server Components (`"use client"`) centered around `documentation-panel.tsx`, which owns the per-entity document list state (documents, analyses, loading/error/busy flags) and composes all child surfaces. It loads documents via `documentsApi.getEntityDocuments` and merges per-document analysis states from `documentationIntelligenceApi.getAnalysis` using `applyAnalysisState`. CRUD mutations are applied optimistically through pure updater functions (`applyDocumentCreated`, `applyDocumentUpdated`, `applyDocumentRemoved`) rather than refetching. The panel renders four sibling dialogs — `AddDocumentationDialog`, `EditDocumentationDialog`, `DocumentAnalysisDialog`, and `ComponentSpecificationIntelligenceDialog` — plus shared `VersionHistoryDialog`, `DocumentViewer`, and `ConfirmDialog` from `@/components/ui`. `DocumentationCard` is a presentational leaf that renders metadata, tags, confidentiality badges, and action buttons whose visibility depends on `isExternalReference` and `canPreviewDocument`. Analysis flows delegate decision and apply actions to the existing `componentReviewQueueApi` endpoints, so this module provides only new presentation surfaces over the shared Component Review Queue workflow; it never implements its own review backend. Dependency direction: components depend on `@/lib/api/*` for HTTP calls, `@/lib/component-documentation` and `@/lib/document-intelligence` / `@/lib/specification-intelligence` / `@/lib/attribute-value-review` for pure state transformers and label/formatters, and `@/components/ui/*` for primitive UI building blocks.
