Flat collection of single-file React components under `apps/web/components/ui/`, each exporting one or more cohesive primitives (e.g. `button.tsx` exports `Button` + `buttonVariants`; `dialog.tsx` exports the full Dialog compound: Root, Trigger, Portal, Overlay, Content, Header, Footer, Title, Description, Close). Low-level primitives (`input`, `select`, `checkbox`, `switch`, `radio-group`, `tabs`, `popover`, `tooltip`, `separator`, `label`) wrap `@base-ui/react` primitives with Tailwind styling via `cn()` from `@/lib/utils`. Higher-order composites (`form.tsx`, `field.tsx`, `command.tsx`, `drawer.tsx`, `accordion.tsx`, `bulk-action-toolbar.tsx`, `entity-data-table.tsx`, `workflow-builder.tsx`, etc.) compose these primitives into domain-specific widgets. The module has a clear dependency direction: business-facing widgets depend on form/input primitives, which depend on Base UI; there are no cross-imports between sibling widgets except through shared primitives like `Dialog`, `Button`, `Field`, and `Form`. Styling is exclusively class-based via Tailwind utility classes and `class-variance-authority` variants — no CSS modules or styled-components.
