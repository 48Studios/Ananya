Three sibling sub-packages under `apps/web/components/`, one per business domain (cycle-counts, rma, warranty). Each form is a standalone React Server Component marked with `"use client"` that owns its own schema (zod), state, and submission logic; there is no shared base form component. Forms are rendered inside `DialogShell` / `DialogShellBody` / `DialogShellFooter` from `@/components/ui/dialog-shell` and consume UI primitives (`Button`, `Input`, `Field`, `SearchableSelect`) from `@/components/ui`. Data access goes exclusively through typed API clients in `@/lib/api/*` (`cycleCountsApi`, `rmaRequestsApi`, `warrantyClaimsApi`, plus reference catalogs like `componentsApi`, `locationsApi`). The cycle-counts sub-package has two cooperating components: `CycleCountForm` creates/updates a count header + line items, while `RecordCountsModal` opens against an existing count to record per-line physical quantities and compute variance client-side. Cross-cutting concerns (loading spinners, server error banners, submit-state disabling) are implemented inline rather than extracted.
