Children are split by concern rather than feature: `ui/` holds Base UI/Radix primitives consumed everywhere; `charts/`, `barcode/`, `scanner/`, and `documentation/` are cross-domain feature surfaces; every other subdirectory is a single-purpose form component (one file per entity) that composes primitives from `ui/` and submits via typed API clients. Top-level files (`dashboard-layout.tsx`, `command-palette.tsx`, `theme-provider.tsx`, `pwa-register.tsx`, `app-footer.tsx`) provide the application shell that wraps pages. There is no runtime wiring between children — they are pure React trees imported directly by page routes under `apps/web/app/`. Cross-child sharing happens only through the `ui/` primitive layer and shared Zod schemas/API clients located outside this scope.
