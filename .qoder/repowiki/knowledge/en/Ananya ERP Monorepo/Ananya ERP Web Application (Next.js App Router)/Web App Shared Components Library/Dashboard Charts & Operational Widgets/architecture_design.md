Two sibling sub-folders with distinct responsibilities:
- `charts/` — pure presentational chart components built on `recharts` (`AreaChartWidget`, `BarChartWidget`, `DonutChartWidget`) plus a shared `ChartCard` shell (title/subtitle/action slot) from which they are typically embedded. Each widget owns its own typed data interface (`*ChartDataItem`) and props, renders an empty state when data is missing, and uses CSS `var(--*)` tokens for theme-aware grid/tooltip styling.
- `dashboard/` — higher-level operational cards (`DashboardAttentionQueue`, `DashboardOperationsPipeline`, `DashboardQuickActionsCard`) that compose domain DTOs (`PurchaseOrderDto`, `WorkOrderDto`, `StockAdjustmentDto`, `NotificationDto`) from `@/lib/api/*`, transform them into in-memory lists via `React.useMemo`, and render status badges, progress bars, and navigation links using shared UI primitives (`Button`, `StatusBadge`) and `lucide-react` icons.

Dependency direction is one-way: dashboard widgets import domain DTO types and shared UI; chart widgets depend only on `recharts` and `@/lib/utils`. There is no cross-import between `charts/` and `dashboard/`; composition happens at the page level where both are placed side by side.
