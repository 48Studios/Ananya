React client components built on `react-hook-form` + `@hookform/resolvers/zod` for schema-driven validation, `lucide-react` icons, and shadcn-style UI primitives (`Button`, `Input`, `SearchableSelect`, `DialogShell*`, `Field*`) consumed from `@/components/ui/*`. Data access goes through typed API modules under `@/lib/api/*` (purchase-orders-api, suppliers-api, components-api, goods-receipts-api, etc.).
