Each subdirectory under `apps/web/components/` exposes a single self-contained form component (e.g. `WorkOrderForm`, `BomForm`, `MaintenanceForm`, `MaterialConsumptionForm`, `FinishedGoodsForm`) plus one or more modal wrappers (`RecordOutputModal`, `RecordScrapModal`). Forms are pure presentational + stateful React components with no server logic — they call domain-specific API clients from `@/lib/api/*` (`work-orders-api`, `boms-api`, `maintenance-api`, `material-consumption-api`, `finished-goods-api`, `components-api`, `locations-api`) and surface results via `onSuccess` / `onCancel` callbacks. UI is built on the shared `@/components/ui` primitives (`DialogShellBody/Footer/CancelButton`, `Field/FieldLabel/FieldError`, `SearchableSelect`, `Input`, `Select`) and uses `react-hook-form` with `zodResolver` for validation; complex forms (BOM) use `useFieldArray` for dynamic line items. Dependency direction is strictly inward: this module depends on `@/lib/api/*` and `@/components/ui/*` but is not imported by them.
