Three Next.js App Router route groups under `apps/web/app/`: `sales/` (single list page), `sales-orders/` (list + `[id]` detail), and `quotations/` (list + `[id]` detail). Each page is a React client component (`"use client"`) that composes shared UI primitives from `@/components/ui` — `PageHeader`, `StatCard`, `EntityDataTable`, `StatusBadge`, `Button`, `Tooltip*` — and formats values via `@/lib/utils` (`formatCurrency`, `formatDate`). Data is entirely in-process: each page declares an interface for its record type and seeds it with a local `mock*` array wrapped in `React.useState`, so there is no API/data-layer dependency inside this module. List pages render KPI stat cards plus a filterable `EntityDataTable` with `ColumnDef` columns; detail pages use `next/navigation`'s `useParams()` to read the dynamic `[id]` segment and present a header with action buttons (e.g. "Dispatch Shipment", "Convert to Sales Order") alongside a static line-items table.
