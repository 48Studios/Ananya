Three Next.js App Router route groups under `apps/web/app/`, each exposing a list page plus an optional `[id]` detail page:
- `projects/` — `page.tsx` renders a filtered/sortable `EntityDataTable` of `ProjectDto` with KPI stat cards and a `DialogShell` + `ProjectForm`; `[id]/page.tsx` is the project detail view implementing the full project lifecycle (start/pause/complete/archive/cancel) and three material workflows (allocate from inventory projections, issue allocated stock, return issued stock) that call `projectsApi`, `componentsApi`, `locationsApi`, and `inventoryProjectionsApi`.
- `tasks/` — lightweight CRUD list/detail over `TaskDto` via `tasksApi`, using `StatusBadge` and a `TaskForm` in a dialog.
- `time/` — single list page logging `TimeEntryDto` rows via `timeEntriesApi` with a `TimeEntryForm` dialog.

All pages are `"use client"` React components; data fetching is done locally inside the component with `useState`/`useEffect`/`useCallback`/`useMemo` rather than server actions or RSC loaders. Cross-cutting UI comes from shared primitives under `@/components/ui/*` (`PageHeader`, `StatCard`, `EntityDataTable`, `DialogShell`, `Button`, `Field`, `SearchableSelect`, `ConfirmDialog`, `LoadingState`, `ErrorState`) and domain forms live under `@/components/projects|tasks|time/*`. API contracts are imported from `@/lib/api/*` modules typed by their corresponding `*Dto` types.
