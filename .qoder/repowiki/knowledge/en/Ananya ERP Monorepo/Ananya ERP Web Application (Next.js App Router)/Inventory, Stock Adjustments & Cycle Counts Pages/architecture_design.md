Each route is a standalone React Server Component marked `"use client"` under Next.js App Router (`apps/web/app/<feature>/page.tsx`, with a `[id]/page.tsx` detail route for stock adjustments). Data fetching is performed client-side via `React.useEffect` calling typed API clients from `@/lib/api/*` (`componentsApi`, `categoriesApi`, `locationsApi`, `inventoryTransactionsApi`, `stockAdjustmentsApi`, `cycleCountsApi`). Cross-entity lookups (e.g. category names, location names, component details) are materialized in local `Map`/`Record` state via `useMemo`. List views render through a shared `EntityDataTable` component with column definitions built as `ColumnDef[]` arrays; detail views compose `PageHeader`, `StatCard`, `ConfirmDialog`, `LoadingState`, and `ErrorState` UI primitives. Mutations (approve, cancel, delete, create) are triggered by button handlers that call the corresponding API method and update local state on success, with confirmation dialogs guarding destructive actions. The module depends outward only on shared UI components (`@/components/ui/*`) and API clients — no cross-route imports exist between these three feature folders.
