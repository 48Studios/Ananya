Each route is a Next.js `page.tsx` marked `'use client'`, rendering React components that fetch data via typed API clients (`@/lib/api/purchase-orders-api`, `@/lib/api/purchase-invoices-api`, `@/lib/api/suppliers-api`, `@/lib/api/components-api`, `@/lib/api/goods-receipts-api`) and compose UI from shared primitives under `@/components/ui` (PageHeader, StatCard, EntityDataTable, DialogShell, ConfirmDialog, LoadingState, ErrorState). The module follows a consistent two-page-per-entity pattern: a list page (`purchase-orders/page.tsx`, `purchase-invoices/page.tsx`) renders an `EntityDataTable` with column definitions, filter configs, and action buttons; a detail page (`[id]/page.tsx`) loads the entity plus related records in parallel via `Promise.all` and displays them in sectioned cards. Business state transitions (submit/cancel/delete PO; approve/pay/cancel invoice; run 3-way match) are handled inline with optimistic local state updates and toast-style notice banners. Cross-entity navigation links POs to suppliers, components, goods receipts, and invoices through relative `Link` routes. Shipping carrier integration is delegated to `@/lib/shipping-carriers` for provider name resolution and auto-tracking URL generation.
