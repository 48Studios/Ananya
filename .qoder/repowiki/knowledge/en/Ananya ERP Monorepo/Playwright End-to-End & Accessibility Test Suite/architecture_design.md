Tests are organized by feature area under `tests/e2e/<domain>/` (authentication, dashboard, procurement, manufacturing, etc.), with a parallel `tests/accessibility/` suite for WCAG audits and `tests/page-objects/` for reusable UI abstractions. A single shared fixture at `tests/fixtures/test.fixture.ts` extends Playwright's base test to inject page-object instances (`loginPage`, `dashboardPage`, `componentsPage`, `settingsPage`) as fixtures and registers global `console`/`pageerror` listeners that collect errors before each test. Page objects encapsulate locators and actions per screen; specs import the custom `test`/`expect` from the fixture rather than directly from `@playwright/test`. Visual regression snapshots live alongside their spec in `tests/e2e/visual-regression.spec.ts-snapshots/` and use `toHaveScreenshot` with a 0.05 max diff pixel ratio. Accessibility tests use `@axe-core/playwright`'s `AxeBuilder` against WCAG 2.1 tags.
