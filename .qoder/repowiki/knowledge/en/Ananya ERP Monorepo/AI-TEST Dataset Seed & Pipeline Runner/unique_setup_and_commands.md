Requires a session token in `ANANYA_TOKEN` or a file at `/tmp/ai-test-token.env` containing a token matching `aitest-seed-*`, plus a running API at `http://localhost:4000` and a PostgreSQL container named `ananya-db` (overridable via `ANANYA_DB_CONTAINER`). Typical workflow: `node tools/ai-test-dataset/verify-extraction.mjs` → `node tools/ai-test-dataset/seed.mjs` → `node tools/ai-test-dataset/run-pipelines.mjs` → `node tools/ai-test-dataset/report.mjs` → `node tools/ai-test-dataset/cleanup.mjs --execute`. Cleanup defaults to dry run; `--include-library-findings` additionally removes pre-existing Data Pack attribute findings.
